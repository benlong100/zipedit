# Notes from the Apple //e

This editor is written in 6502 assembly and runs under ProDOS 8 on an Enhanced Apple //e with 128K. The text you are reading was inserted into auxiliary memory one byte at a time, then read back out of it to draw this screen.

## How it writes

- lines hard wrap near column 76, so one line is one screen row
- **bold** with Ctrl-B, *italic* with Ctrl-I
- `code` spans and [links](url) are typed literally
- Open-Apple-? toggles the cheat sheet below
